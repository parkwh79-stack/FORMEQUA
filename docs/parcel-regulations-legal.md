# 필지 지정사항과 법정 밀도 적용 검토

검토일: 2026-10-21. Korean Law MCP의 법령·자치법규 원문으로 기존 계산 스냅샷과 대조했습니다. 필지별 GIS 조회 결과를 일반 조례에 대응하는 범위와, 개별 계획을 추가로 확인해야 하는 범위를 구분합니다.

## 개별 계획과 강화·완화

국토법 제50조는 지구단위계획구역과 계획을 도시·군관리계획으로 결정하도록 합니다. 제52조는 건축물의 용도·건폐율·용적률·최고·최저 높이와 건축선 등의 계획 사항을 규정하고, 제54조는 계획구역 내 건축·용도변경 등이 그 계획에 맞아야 한다고 규정합니다. 제53조의 지정·계획 실효 규정도 있으므로 구역 이름이나 오래된 고시번호만으로 현행 적용 상한을 확정하지 않습니다.

서울 조례 제50조의 준공업지역 공동주택·오피스텔 등 250% 강화와 상업지역 주거복합 별표 조건은 기존 `legal-rules.js`의 사용 조건과 함께 적용합니다. 공공시설 제공 등을 통한 준공업지역 완화나 제51조의 임대주택·관광숙박·공공기여 완화는 승인된 계획·심의·용도·기여 조건을 검토해야 합니다. 관광호텔 선택, 필지 합집합, 공공기여 비율 입력만으로 120%·130% 등의 보너스를 지급하지 않습니다.

이번 연결은 공식 출처와 개별 고시번호·URL을 갖춘 필지별 상한 입력 중 일반 조례보다 낮은 강화 상한만 보수적 비교 조건으로 적용합니다. 완화·중첩 적용이나 인센티브 자격을 자동 승인하지 않습니다. 숫자 0인 실제 계획 상한은 기존 화면의 `0=미입력`과 충돌하므로 자동 적용을 보류하고 별도 확인을 요구합니다.

## 복수 용도지역

국토법 제84조제1항은 요건을 충족하는 복수 용도지역 등의 대지에 대해 부분별 면적과 비율을 사용한 가중평균을 규정합니다. 시행령 제94조의 작은 부분 규모는 일반적으로 330㎡이며, 도로변 띠 모양 상업지역에 걸치는 경우에는 660㎡입니다. 고도지구·방화지구·녹지지역에는 제84조의 별도 적용 규정이 있습니다. 따라서 두 용도지역의 이름만 알아서는 높은 용적률이나 단순 평균을 적용할 수 없습니다.

현재 연결은 각 필지 전체의 99.9% 이상을 차지하는 한 개 지원 용도지역이 있고 합필 대상도 모두 같은 지역인 경우만 자동 대응합니다. 99.9%는 공간 연산 오차를 위한 구현 기준이며 법정 허용 오차가 아닙니다. 서로 다른 지역, 분할 면적·점유율 미확인, 중복 지역, 미지원 지역은 자동 대응하지 않습니다. 복수 지역 가중평균·고도·방화·녹지 예외를 확정하는 기능은 포함하지 않습니다.

## 법령 MCP와 필지 조회의 역할

이번에 연결된 Korean Law MCP는 법률·시행령·조례 조문과 별표를 조회합니다. 도구 검색에서 특정 PNU의 토지이용계획·도시계획 GIS 지정사항을 반환하는 기능은 확인되지 않았습니다. 조문 검색만으로 어느 지번이 어떤 지구단위계획·용도지역·보호구역에 속하는지 증명할 수 없습니다.

지번·경계와 지정사항의 공간 교차는 별도의 공식 GIS 자료로 확인하고, 개별 계획의 고시·시행지침·효력·특별조건은 원문과 관할 기관에서 확인해야 합니다. [토지이음 토지이용계획 열람](https://www.eum.go.kr/web/ar/lu/luLandDet.jsp)은 지번별 열람과 고시정보를 별도로 제공합니다. `status: verified`나 `source: vworld`는 공급자 응답·입력 데이터의 상태이며 저장 파일에서 재전달되었다고 공적 인증이 되는 것은 아닙니다.

## 공통 모듈 계약

`parcel-regulation-rules.js`는 브라우저의 `AtelierParcelRegulations`와 Node `require()`에서 동일하게 사용합니다.

- `sanitizeRegulations(value)`: PNU, 상태, 용도지역·점유율·교차면적, 지구단위계획, nullable 상한, 공식 HTTPS 출처·날짜·안내의 형식과 범위를 검증합니다. 미확인 숫자를 0으로 바꾸지 않습니다.
- `resolve(regulationOrArray, params, AtelierLegal)`: 서울 PNU, 공식 출처, `verified` 또는 `partial` 상태, 명확한 단일 용도지역과 99.9% 이상 점유율을 확인해 `inputs.zoning`과 일반 규칙을 반환합니다. 계획 수치 미확인 때문에 `partial`이더라도 용도지역 자체의 전체 점유가 확인되면 지역 대응은 가능합니다.
- 계획 상한은 모든 대상의 확인 상태·고시번호·공식 URL·필드별 수치가 갖춰진 경우에만 강화 입력으로 적용합니다. 불완전하거나 완화된 상한은 추가 확인 대상으로 남깁니다.
- 반환 `liveParcelVerified`·`isPermitConfirmation`은 `false`입니다. 규칙 대응과 법적 권리 확정을 혼동하지 않습니다.

회귀 테스트: `node tests/parcel-regulation-rules.test.js`.

## 원문 증거

`law-evidence/parcel-regulation-2026-10-21-*.json`에 MCP 응답을 보관했습니다. 조문별 원문은 `national-50`~`national-54`, `national-76`~`national-78`, `national-84`, `decree-84`, `decree-85`, `decree-94`, `seoul-44`, `seoul-48`, `seoul-50`, `seoul-51` 파일입니다. `ordinance-search-latest`에는 서울 조례 식별자와 시행일 검색 결과가 있습니다.

최초 시행일 직접 지정 호출은 외부 API 오류를 반환하여, 법령ID로 현행 본문을 다시 조회하고 응답에 표시된 시행일을 확인했습니다. 외부 오류 응답을 근거 조문으로 사용하지 않았습니다.
