# 비공개 주간 검토 JSON · 수동 포트폴리오

검토 기록을 모아 운영자가 살펴보고, 직접 만든 이미지를 선정해 홈페이지에 등록합니다. 이미지 생성 API·공급자 설정·API 키·생성 작업자는 사용하지 않습니다. 공공 필지·주소·법령 API 설정은 계속 사용합니다.

## 무엇이 저장되는가

유효한 필지에서 사용자가 설계·법규·사업성 조건을 변경하면 현재 검토를 비공개 JSON으로 보관합니다. 첫 화면·프로젝트 불러오기·카메라 조작만으로는 접수하지 않습니다. 내용과 필지 식별자가 같은 중복은 제한하며, 사업성 입력 변경은 새 기록으로 보관합니다.

- 주소·PNU·합필 대상, 실제 필지 경계와 확보된 도로·주변 자료
- 프로젝트 복원용 입력, 용도와 옵션, 외장재, 층별 매스와 면적
- 법규 기준·조회 근거·적용 가정과 아직 확인하지 않은 항목
- 실제 계산된 주차·코어·층별 실내 평면과 수량
- 사업성 입력과 결과, 비교 대안, 현금 흐름과 토지가격 검토

아직 생성하거나 조회하지 않은 자료는 미생성/미확인 상태로 기록합니다. JSON 변환 과정에서 숫자가 유효하지 않거나 객체를 저장할 수 없으면 경고 경로를 기록합니다. 인증키·브라우저 저장소·DOM·실행 함수는 검토 자료에 포함하지 않습니다.

로컬 원본은 프로젝트 상위 `.pilot-data/study-review/records/<id>.json`에 보관하고 SQLite에 인덱스를 둡니다. `ARCHIVE_DB_PATH`로 로컬 위치를 지정할 수 있습니다. Cloud Run은 임시 디스크 대신 `ARCHIVE_BACKEND=gcs`와 `ARCHIVE_BUCKET`으로 비공개 Cloud Storage를 사용합니다. 원본 JSON은 불변 객체이고 수동 검토 상태는 인덱스와 합쳐 내보냅니다. 보호 설정이 없는 버킷이나 연결 실패를 정상 저장으로 처리하지 않습니다. 자료는 일주일이 지나도 삭제하지 않습니다. 파일럿 한도는 기록 10,000개, 기록·예약·이미지 누적 1GiB, 요청당 최대 20MiB입니다. [Google 배포·인증 설정](cloud-deployment.md)을 참고하세요.

## 주간 모음

프로젝트의 `seoul-3d-web` 폴더에서 다음 명령을 실행합니다.

```powershell
python study_review_tools.py weekly --days 7
```

처음에는 최근 7일, 다음부터는 지난 보고서 이후 새 기록을 `.pilot-data/study-review/weekly/reviews-날짜-시간.json`으로 내보냅니다. PC가 꺼져 실행을 놓쳤다면 다음 실행에서 지난 기준일 이후 자료를 포함합니다. 콘솔과 알림에는 건수·기간·파일 경로만 표시합니다. 클라우드 자료를 받을 운영자 PC와 기존 주간 알림 실행 환경에는 GCS 환경변수·ADC 인증을 설정해야 합니다. 이 코드 변경은 주간 알림을 새로 만들거나 기존 알림 환경을 자동 변경하지 않습니다.

알림 기준일을 바꾸지 않고 최근 7일을 다시 받을 때는 `weekly --days 7 --preview`를 사용합니다. 특정 주차는 `export-week --week 2026-W43`으로 받습니다. 주차는 한국시간 월요일~일요일이며 기간의 끝은 포함하지 않습니다.

주소·PNU·금융정보가 들어 있는 전체 JSON은 HTTP 다운로드 경로로 제공하지 않습니다. 방문자는 자신의 검토를 접수하며, 운영자는 로컬 파일이나 보호된 서버 파일 접근으로 주간 JSON을 확인합니다. 공유 대시보드 암호만으로 모든 방문자의 검토 원본을 조회하는 화면은 만들지 않습니다.

## 직접 만든 이미지 등록

JSON의 `reviewData.project`는 프로젝트 파일 불러오기에 사용할 수 있습니다. 필요한 경우 아래 명령으로 따로 추출합니다.

```powershell
python study_review_tools.py export-one --id 검토ID --project --output "C:\작업폴더\project.json"
```

JSON과 모형을 살펴보고 직접 이미지 파일을 만든 뒤, 공개해도 되는 내용인지 확인하고 아래 명령으로 등록합니다.

```powershell
python study_review_tools.py publish --id 검토ID --image "C:\작업폴더\완성이미지.png"
```

이미지는 PNG·JPEG·WebP 10MB 이하이며 서버에서 PNG로 정규화합니다. 홈페이지에는 선정 이미지·용도·개념 안내만 표시하고 주소·PNU·사업성·원본 JSON은 포함하지 않습니다. 이미지 픽셀에 주소나 금융정보가 보이면 운영자가 먼저 지우고 등록해야 합니다. `AI VISUAL STUDY`는 기존처럼 `+`로 접힌 상태를 유지합니다.

이전 자동 생성 시도의 요약·원본은 이전 비공개 데이터베이스에 남아 있을 수 있지만 새 공개 피드와는 연결하지 않습니다. 새 전체 검토 JSON 기능을 켜기 전 누락된 검토 항목은 과거 기록에서 소급 복원할 수 없습니다.
