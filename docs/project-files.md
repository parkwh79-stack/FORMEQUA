# FORMEQUA 프로젝트 파일 v1

상단의 **프로젝트 파일**을 열어 이름을 정한 뒤 **프로젝트 저장**을 누르면 `.formequa.json` 파일을 내려받습니다. **불러오기**에서 파일을 선택하면 모든 필지의 입력을 검증한 뒤 활성 설계를 복원하고, 현재 엔진과 법령 기준으로 면적·실내 평면·주차·사업성을 다시 계산합니다. 파일을 읽기 위해 서버에 업로드하지 않습니다.

같은 탭의 임시 보관은 기존처럼 마지막 변경 후 12시간입니다. 프로젝트 파일에는 만료 기간이 없습니다. 다만 법령과 엔진이 바뀌면 같은 입력의 재계산 결과가 달라질 수 있으므로, 기존 분석 결과를 비교하려면 **분석 저장** 자료를 함께 보관해야 합니다.

## 보관 범위

- 현재 필지와 방문하여 수정한 필지별 설계 입력: 역삼·성수·합정·을지로·직접 입력 대지.
- 매스·외장재·층별 용도·법규 조건·주차 조건·임대 및 호텔 운영 가정·자본 구조.
- 검증된 필지 경계 `parcelData`가 있다면 최대 **5개 필지(Feature)**의 EPSG:4326 Polygon/MultiPolygon 자료와 PNU·주소·출처. 주소 검색 후보 최대 10개와 실제 적용 한도 5개는 서로 다릅니다.
- 프로젝트 이름, 생성 날짜, 저장 날짜. 화면의 날짜는 서울 시간으로 표시합니다.

계산 결과, 법령 원문 응답과 조회 캐시, 비밀키, API 인증정보, 녹화 상태, 선택 중인 층 등 임시 뷰어 상태는 포함하지 않습니다. 파일에 포함된 PNU·주소·경계가 현재 공공자료의 최신 정보인지 인증하는 기능은 아닙니다. 프로젝트 파일에는 입력한 금융 가정과 주소가 포함되므로 공유 대상을 고려해 보관해야 합니다.

## 형식

```json
{
  "format": "formequa-project",
  "version": 1,
  "title": "합정 리빙 연구",
  "createdAt": "2026-10-21T00:00:00.000Z",
  "savedAt": "2026-10-21T01:00:00.000Z",
  "activeParcelKey": "custom_seoul",
  "inputs": { "parcelKey": "custom_seoul", "floorsAbove": 10 },
  "perParcel": {
    "custom_seoul": { "parcelKey": "custom_seoul", "floorsAbove": 10 }
  }
}
```

위 예시는 구조 설명용으로 입력 일부만 표시했습니다. 실제 저장 파일은 입력 허용 목록을 사용하여 가능한 모든 현재 입력을 기록합니다. `inputs`와 활성 `perParcel`의 값이 서로 다르면 파일을 거부합니다. 알 수 없는 최상위 항목·입력·필지, 범위 밖 수치, 숫자 대신 문자열, 지원하지 않는 enum, 유효하지 않은 층별 용도와 경계, 지원하지 않는 버전은 오류입니다. 일부 잘못된 항목만 몰래 빼고 복원하지 않습니다. 필지별 입력을 모두 검증하기 전에 현재 설계를 바꾸지 않습니다.

최대 파일 크기는 **5 MiB**입니다. GeoJSON은 `AtelierParcelGeometry.sanitizeParcelData`의 필지 수·좌표 수·지역 범위·기하 형식 검증과 `derive`의 연결된 합집합·매스 내부 영역 검증도 통과해야 합니다. 실제 경계 면적이 현재 입력 지원 범위인 **200~20,000㎡**를 벗어나거나 서로 떨어진 경계이면 복원 전에 파일을 거부합니다. 세션 저장 용량이 부족해도 원본 프로젝트 파일은 변경하지 않습니다.

## JavaScript 인터페이스

`AtelierWorkspace`는 기존 세션 API에 다음을 추가합니다.

| 함수 | 동작 |
| --- | --- |
| `exportProject({title})` | 현재 입력과 필지별 입력으로 검증된 v1 객체 생성. 임시 상태는 허용 목록에서 제외. |
| `parseProject(jsonText)` | 크기 제한·JSON 파싱·전체 스키마 검증. 원본 텍스트 불변. |
| `validateProject(object)` | 원본 객체를 변경하지 않고 정규화된 입력 사본 반환. 오류 시 throw. |
| `importProject(objectOrJson, apply)` | 전체 검증 후 `apply(inputs, project)`를 호출. 기존 `loadParcelPreset` 경로로 UI와 계산 복원. |
| `getProjectMeta()` | 현재 탭에 보관된 이름·생성 날짜. |

최신 호텔 필드가 없는 이전 세션 입력에는 현재 엔진 기본값을 보충합니다. 화면은 객체를 통째로 교체하지 않으며, 기존 `loadParcelPreset` → 입력 UI 동기화 → 재계산 경로를 사용합니다. 복원 중 `atelier:updated`가 발생해도 필지별 입력을 중간 상태로 저장하지 않습니다.

검증: `node tests/project-files.test.js`.
