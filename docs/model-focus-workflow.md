# 상세 보기 → 모형 집중 → 상세 작업실 (2026-10-23)

사용자 요청으로 홈페이지의 ‘상세 보기’ 첫 화면을 전체 대시보드에서 모형 집중 화면으로 변경했다.

## 화면 흐름

1. 홈페이지의 상세 보기는 `dashboard.html?view=model`로 이동한다. 선택 필지와 설계 입력, 복귀 위치를 기존 작업 상태 연결로 전달한다.
2. 집중 화면은 상단 작업실 헤더와 설계·금융·법규 패널을 접고 WebGL 모형을 크게 보여준다. 왼쪽에는 ‘형태·높이 / 외관·재료’ 편집 패널, 오른쪽 위에는 ‘동영상 저장’과 ‘상세 작업실 열기’가 있다.
3. ‘상세 작업실로 돌아가기’ 또는 Esc를 누르면 같은 페이지에서 전체 대시보드가 열린다. 진입 링크에 있던 설계 챕터·분석 탭은 이 시점에 적용한다.
4. URL은 `view=workspace`로 바뀌므로 새로고침해도 전체 작업실을 유지한다. 작업실의 ‘모형 집중’으로 다시 집중 화면에 들어갈 수 있다. 별도 `view` 지정 없이 상세 페이지에 들어오면 모형 집중을 기본으로 사용한다.
5. 2026-10-24 요청에 따라 모든 FORMEQUA 로고·모형 편집 패널의 브랜드·‘아뜰리에로’ 복귀 링크는 홈페이지 최상단 `#home`으로 이동한다. 진입 URL의 `returnTo`가 이전 구간이어도 홈페이지 맨 위로 복귀하며, 설계 입력 저장은 유지한다.

HTML의 초기 집중 클래스가 복잡한 대시보드의 순간 노출을 줄인다. WebGL 로딩에 실패하면 전체 작업실과 기존 안내로 복귀한다.

## 외관 팔레트

기존 `hudFacadeQuickStudio` DOM을 집중 화면의 왼쪽 호스트로 이동한다. 복제한 입력이나 별도 팔레트 상태를 만들지 않는다. 복귀 시 원래 위치와 접힘 상태로 돌려놓으므로 기존 재료·색상·유리·입면 이벤트와 저장 값을 그대로 사용한다.

집중 화면에서는 색상 → 외장 질감 → 유리 틴트 → 입면 패턴 순서로 표시한다. 실제 색감 전환도 제공하며, 기존 재료 표현 모듈을 사용한다. 유리 색상의 글자 대비와 선택 버튼의 `aria-pressed`, 펼침 버튼의 `aria-expanded`를 동기화한다. 집중 화면의 3D 치수선은 표현만 숨기고 사용자의 치수 표시 입력을 변경하지 않는다.

데스크톱은 팔레트가 모형 왼쪽에 있으며 캔버스 영역을 따로 확보한다. 모바일에서는 팔레트를 아래쪽의 스크롤 가능한 영역으로 배치하고, 색상 칩을 먼저 보여준다. 접으면 모형이 더 넓어진다.

## 형태와 높이 조정 (2026-10-24 추가)

집중 화면의 첫 탭은 ‘형태·높이’다. 지상 층수(1~35층), 기준층 층고(3.0~5.2m), 목표 건폐율(25~60%)을 기존 범위에서 조정한다. 세 입력의 원래 DOM을 `modelFocusMassControls`로 옮기고 복귀 시 같은 위치에 돌려놓는다. 별도 상태나 두 번째 계산식을 만들지 않는다. 작업실·세션·프로젝트 저장·분석 API에서 사용하는 입력 계약은 유지한다.

타워형(A: 포디움+타워), 중정형(B: 중정+테라스), 북측 코어형(C)의 버튼은 기존 대안 선택 버튼을 호출한다. 이에 따라 매스·코어·면적·주차·사업성이 같은 경로로 다시 계산된다. 임의 곡면이나 자유 변형 편집기를 추가한 것은 아니다. 층수·층고 조정은 현재 건물의 실제 생성 높이를 바꾸며, 팔레트의 색상 표현 전환과 구분된다.

현재 모형 높이와 실제 적용 층수/요청 층수를 구분해서 표시한다. 법규·대지·주차·코어 조건 등으로 요청 층수가 모두 생성되지 않으면 안내 문구를 표시하며 한도를 자동 해제하지 않는다. 두 탭 전환은 설계 입력을 바꾸지 않고 키보드 좌우·Home·End 탐색을 지원한다. 모바일은 모형 아래에 스크롤 가능한 패널을 배치한다.

격리된 Edge 브라우저에서 실제 키보드 슬라이더 조작과 A/B/C 선택을 검증했다. 모형·면적·주차·사업비를 새 공통 계산 결과와 대조하고, 외관 전환·작업실 복귀·재진입·새로고침 후 입력 유지·모바일 조작을 포함해 25개 검사를 통과했다. 검증 중 비공개 검토 접수는 차단했다. 결과는 [검증 기록](model-focus-mass-verification-20261024.json)에 남긴다.

## 층 선택·실내 평면·확대 진입 (2026-10-24 추가)

집중 도구막대의 ‘실내 평면 생성’은 기존 LIVE FLOOR PLAN 카드를 오른쪽 패널로 옮겨 연다. 새 평면 생성기나 두 번째 수량 원장을 만들지 않는다. `realyticsPlanCard`의 원래 DOM과 이벤트·SVG·큰 도면·저장·층 선택을 그대로 사용하고, 패널을 닫거나 작업실로 돌아가면 원래 분석 위치에 돌려놓는다. 데스크톱은 캔버스와 오른쪽 패널 영역을 나누며 모바일은 모형 아래에 스크롤 가능한 평면 패널을 배치한다.

실제 3D 층 클릭은 `atelier:floor-selected`로 전달한다. 간략 매스라면 기존 `selectModelDetail`의 change 경로로 개념 상세를 생성한 뒤 같은 층을 표시한다. 실내·코어가 미완료인 경우 원래의 미완료 상태와 안내를 유지한다. 지하층은 지하 실내 미생성 안내를 표시하며 이전 지상층의 평면을 대신 보여주지 않는다.

`AtelierInteriorViewer`의 open/exit/isActive/getState와 `atelier:interior-change`를 통해 선택 층·3D 시점·오른쪽 평면을 연결한다. 활성 실내에서 다른 층을 선택하면 3D도 해당 층으로 바뀐다. 같은 층에서 실명·가구 표시만 바꾸면 보행 위치와 카메라는 유지한다. 최신 계산 결과와 다른 이벤트는 무시하고 같은 층의 재진입을 막아 이벤트 재귀를 방지한다.

확대로 실제 층 안에 들어가면 실내 투시와 오른쪽 평면을 함께 연다. 집중 모드의 간략 매스는 `atelier:interior-request`를 받아 같은 상세 전환 경로로 이어진다. 큰 확대 입력으로 층을 건너뛰는 경우에는 최근 확대 입력과 실제 내부를 통과한 이동만 검사한다. 중정·외부 근접·일반 궤도 회전은 진입으로 취급하지 않고, 코어 미완료·분리 모드 등 기존 차단 조건은 유지한다.

## 작업실 주요 지표 위치 (2026-10-24 추가)

기존 주요 지표 블록을 `workspaceGrid` 뒤의 `dashboardSummary`로 이동했다. 상단은 용도 선택과 작업 영역으로 이어지고, 면적·주차·사업비·자기자본·수익률의 다섯 파일럿 지표는 하단에 표시한다. ID·값·계산식·금융 상세 탭 연결과 파일럿의 여섯 번째 지표 숨김 정책은 유지한다. 집중 모드에서는 이 지표를 계속 숨긴다.

실제 층 raycast 클릭·휠 확대·간략 모형 전환·활성 실내 층 변경·지하층·큰 도면·카메라 보존·호텔·태블릿·모바일·하단 지표를 격리된 브라우저에서 확인했다. [연결 검증 결과](model-focus-floorplan-verification-20261024.json)와 작업공간 `.backups/formequa-focus-floorplan-20261024/`의 스크립트·화면을 함께 보관한다. 단위 회귀 검증은 `tests/interior-entry-focus.test.js`에 추가했다.

## 동영상 저장

`model-video.js`는 현재 WebGL 캔버스를 최대 1600 × 1000 범위, 30fps, 최대 60초로 녹화한다. 시작 후 사용자가 마우스로 움직인 시점과 현재 모형·색상이 영상에 담긴다. ‘녹화 종료·저장’을 누르거나 1분에 도달하면 로컬 동영상 파일을 다운로드한다. 녹화 중 상세 작업실로 돌아가도 먼저 녹화를 마치고 파일을 저장한다.

브라우저의 `MediaRecorder` 지원 코덱을 순서대로 확인해 WebM 또는 MP4를 사용하며, 실제 인코더의 MIME 타입에 맞는 확장자로 저장한다. 현재 모형과 입력·대안을 자동 변경하지 않는다. 화면의 금융 수치·패널·팔레트는 영상에 넣지 않으며 화면 공유나 마이크 권한도 사용하지 않는다. 서버·외부 API로 영상 데이터를 보내지 않는다.

정상 종료·인코더 오류·페이지 종료 시 녹화 스트림과 애니메이션·타이머를 해제한다. 녹화 시작이 실패하면 버튼을 원래 상태로 복구하고 안내한다. 기존 `app.js`의 자동 A/B/C 전환·금융 자막 녹화는 파일럿에서 계속 숨겨 둔 채, 새 모형 녹화 기능만 제공한다.

## 관련 파일

- `editorial.js`, `index.html`: 상세 보기 진입 주소와 캐시 버전.
- `dashboard.html`, `dashboard.js`, `dashboard.css`: 기본 집중 화면, 팔레트 이동·복귀, 전체 작업실 복귀 및 반응형 배치.
- `facade-preview.js`: 유리 색상 칩의 글자 대비 값 제공.
- `model-video.js`: 현재 모형의 로컬 녹화·다운로드.

변경 전 화면 파일과 검증 스크립트·스크린샷·실제 녹화 파일은 작업공간의 `.backups/formequa-model-entry-20261023/`에 보관한다. 브라우저 검증에서는 사용자 연구 JSON 수집을 차단한다. 원래 8090 서버는 계속 실행한다.

## 검증 결과

격리된 Edge에서 34개 확인을 통과했다. 실제 홈페이지 상세 보기 진입, 선택 필지 보존, 팔레트 재배치·색상·유리·실제 색감, 영상 파일 다운로드·디코딩, 입력 불변, 스트림 종료, 인코더 실패 복구, 녹화 중 작업실 복귀, 요청 탭 복원, 모바일 화면·색상 칩 노출을 확인했다. 녹화 파일은 WebM 1120 × 960으로 정상 재생 정보를 읽었으며 실행 오류·로컬 누락 리소스는 없었다. 기존 파일럿 표시 정책과 설계 상태 저장·복원 테스트도 통과했다.
